# Deploy

The website lives in `docs/` and is hosted on **Cloudflare Pages** (direct upload,
no git integration).

- **Project name:** `pokemon-emerald-legacy-solo-leveling-colosseum`
- **Production URL:** https://pokemon-emerald-legacy-solo-leveling-colosseum.pages.dev
- **Cloudflare account:** diogodebastos18@gmail.com (`wrangler` is already logged in via OAuth)

## Deploy command

```sh
wrangler pages deploy docs \
  --project-name=pokemon-emerald-legacy-solo-leveling-colosseum \
  --commit-dirty=true
```

That uploads everything in `docs/` and promotes it to production. The command
prints a unique preview URL plus the production URL above.

## What's in `docs/`

- `index.html` — landing page; embeds an emulator and a pull-up **dex drawer**
  with tabs (Pokédex / Trainers).
- `pokedex.html` — generated by `generate_pokedex.py` (repo root).
- `trainerdex.html` — generated by `generate_trainerdex.py` (repo root).
- `patch.bps`, `title.png`, `safari_ball.png` — static assets.

## Regenerate the dex pages before deploying (if data changed)

```sh
python3 generate_pokedex.py       # -> docs/pokedex.html   (needs Pillow/PIL)
python3 generate_trainerdex.py    # -> docs/trainerdex.html (needs Pillow/PIL)
```

If a generated page's entry count changes, update the matching `count` text in
`docs/index.html` (`DEX_VIEWS` object).

## Checklist

1. (If source data changed) regenerate the affected dex page(s).
2. Eyeball `docs/` locally if needed.
3. `git commit` the changes.
4. Run the deploy command above.
